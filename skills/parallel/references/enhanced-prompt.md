# Enhanced prompt

The polished version of: "Proceed with all the remaining ones with multiple agents in parallel and complete everything without any timeline. I wish to publish as and when ready."

## Full version

```
Proceed with ALL remaining items in this project — every open item from our plan, the task list and the project files, not just the next one.

1. First, list everything that's left as a short ledger: item, the finished deliverable, what it depends on, and whether it needs me (secrets, accounts, payments, approvals, store/portal submissions, public posting). Then start immediately — don't wait for my approval.
2. Run independent items in parallel with multiple agents, launched together. If items must look or read consistently, set up the shared foundation (brand, facts, terminology) first.
3. Complete each item fully — finished, publish-ready output, not outlines or drafts. There's no deadline: prioritise quality and completeness, and don't cut scope to save time. I may be away, so don't stop to ask; take the most reasonable reading and note your assumptions.
4. Verify each deliverable yourself before handing it over, then give it to me as soon as it's ready — don't hold everything until the end.
5. Prepare the items that need me right up to the final click, and tell me exactly what to do.
6. Finish with the ledger showing what's delivered, what's blocked and why, and my remaining actions.

Apply my standing rules to everything you build.
```

## Short version

```
Finish everything that's left, in parallel with multiple agents. List the remaining items first, then go — no approval needed, no deadline, full quality. Check each one and hand it to me the moment it's publish-ready. Prep anything that needs me up to the last click, and end with a status ledger plus my to-dos.
```
