# House rules — Synopus

Copy the block below verbatim into the brief of every agent that builds anything with a user interface (app, website, landing page, dashboard, admin panel, email template rendered as HTML). Check each UI deliverable against it before releasing.

```
HOUSE RULES (non-negotiable for this client)
1. Footer: every page/screen a user or customer sees carries the footer text
   "Designed & Developed by Synopus"
   where "Synopus" (or the whole line) links to https://www.synopus.in
   (open in a new tab). It is present on every such page, including legal pages, FAQs, 404s
   and HTML emails. Internal helper files that only render other assets (a screenshot framer,
   a feature-graphic source) don't need it.
2. Unique, rich, ultra-premium UI. Each product gets its own visual identity — its own palette,
   type pairing, motion and layout rhythm. No stock template look, no default Bootstrap/Tailwind
   starter styling, no reuse of another Synopus product's design. Premium means considered typography,
   generous spacing, refined detail (micro-interactions, depth, polished empty/loading states),
   fully responsive down to phone width.
3. No AI/Claude attribution. Never state or imply the product was built by Claude, Anthropic or "AI":
   no "Built with Claude", "Generated by AI", "Made by an AI assistant" text, HTML comments,
   meta generator tags, README credits or commit messages. The maker is Synopus.
```

## Release check for UI deliverables

- [ ] Footer line present on every user-facing page (incl. HTML emails), exact wording, link resolves to https://www.synopus.in
- [ ] Visual identity is distinct from the other deliverables in this batch (unless they're meant to share one brand — then consistent with the wave-0 foundation)
- [ ] No Claude / Anthropic / AI-generated mention anywhere in visible text, source comments or metadata
- [ ] Looks right at phone width (no horizontal scroll) and desktop
