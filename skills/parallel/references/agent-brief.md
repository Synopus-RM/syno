# Agent brief template

Fill every section. Write it for a capable colleague who has seen none of the conversation. If a section genuinely doesn't apply, write "n/a" rather than deleting it, so it's clear you considered it.

```
ROLE & GOAL
You are producing <deliverable> for <project>, owned by <user / company>.
It will be used by <audience> to <purpose>. It must be finished and ready to publish — not an outline or draft.

CONTEXT YOU NEED
- <product name, one-line description>
- <facts: prices, dates, numbers, URLs, contact details, legal entity name, language(s)>
- <decisions already made: tone, platform, tech stack, what's in / out of scope>
- <how this item relates to the others in the batch, if it does>

INPUTS
- <absolute path> — <what it is>
- Shared foundation (use these, don't invent your own): <absolute paths to brand/facts files>

OUTPUT
- Save to: <absolute path(s)>
- Format: <html / md / xlsx / pdf / code project / ...>

DONE WHEN (check these on your own output before reporting)
- <criterion 1 — observable, e.g. "renders with no console errors at 390px and 1440px">
- <criterion 2>
- <house-rules check, if a UI>

HOUSE RULES
<paste the user's standing rules verbatim — for Synopus, the block in references/house-rules.md>

LIMITS
- Don't post, send, email, deploy to production, submit to any store or portal, or spend money.
- Don't request, invent or hard-code secrets/API keys; leave clearly named placeholders and list them.
- Don't ask questions — take the most reasonable reading, and list what you assumed.
- You work alone on this one deliverable; other agents handle the other items. Don't try to launch agents.
- Don't invent facts the inputs don't give (legal names, addresses, policies, feature claims): leave a visible placeholder like {{REGISTERED_OFFICE_ADDRESS}} and list it.

REPORT BACK (keep it short)
1. What you made, with file paths
2. Assumptions you took
3. Anything only the owner can do (secrets to add, accounts, approvals), with exact steps
4. Your self-check results against DONE WHEN
```
